# BUG-001 - Pedido duplicado ao clicar duas vezes em Finalizar Pedido

## Resumo

Sistema permite criar mais de um pedido quando o usuário clica rapidamente duas vezes no botão Finalizar Pedido.

## Severidade

Crítica

## Prioridade

Alta

## Ambiente

- Aplicação: Automation Practice / QAZANDO Shop
- Navegador: Chrome
- Sistema operacional: Windows

## Pré-condições

- Usuário autenticado
- Produto no carrinho
- Checkout preenchido
- Pagamento com dados válidos

## Passos para reproduzir

1. Acessar o carrinho.
2. Avançar para checkout.
3. Preencher dados válidos.
4. Informar pagamento aprovado.
5. Clicar duas vezes rapidamente no botão Finalizar Pedido.

## Resultado atual

Mais de um pedido pode ser gerado para a mesma tentativa de compra.

## Resultado esperado

Apenas um pedido deve ser criado. Após o primeiro clique, o botão deve ser desabilitado ou a requisição duplicada deve ser ignorada.
